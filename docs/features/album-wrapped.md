# Album Wrapped

Album Wrapped is a planned yearly/periodic listening-story feature built from Groovefolio's local play history.

Possible cards:
- total plays
- most-played album/artist/genre
- first/last play of the period
- favorite side behavior
- listening by month
- rediscovered albums
- new additions vs frequently played records

The current StatsService already supplies some primitives, but Wrapped should be implemented as a separate presentation/business feature rather than overloading the Stats screen.
