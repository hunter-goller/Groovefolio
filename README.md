# Vinyl App 🎵

A personal vinyl collection + listening tracker built with Flutter.

## Goals

- Track vinyl collection
- Log plays (manually + NFC tap)
- View listening stats
- Get recommendations based on listening history

## Tech Stack

- Flutter
- Dart
- Riverpod (state management)
- Drift (SQLite ORM)
- go_router (navigation)

## MVP Features

- Add / edit / delete albums
- Track play history
- NFC tap-to-log plays
- Basic statistics

## Status

In early development 🚧 — migrated from an earlier React Native prototype.

## Getting Started

```bash
flutter pub get
dart run build_runner build
flutter run
```
