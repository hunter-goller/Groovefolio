# Groovefolio design assets

This directory contains design references rather than runtime Flutter assets.

- `branding/` — name/logo/visual identity notes
- `mockups/` — approved/reference UI mockups
- `wireframes/` — low-fidelity layout exploration
- `screenshots/` — implementation screenshots used for review
- `diagrams/` — visual architecture/product diagrams

The current app direction is a compact dark interface with orange accent `#D4622A`, readable album artwork, and deterministic genre chips.
